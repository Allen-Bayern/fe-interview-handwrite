# Craft Fundamentals

> 夯实基础，拥抱变化。

## 项目简介

本仓库最初用于收集前端面试中常见的手写题，旨在帮助开发者备考与巩固核心知识。

随着 AI 时代的到来，各大厂纷纷淡化甚至取消传统前端岗位，技术从业者的能力边界正在被重新定义。基于此，本仓库自即日起进行转型——**不再局限于前端手写题**，而是拓展为一个更为通用的技术基础学习与实践仓库。

## 分支说明

| 分支 | 说明 |
| --- | --- |
| `old-main` | 历史前端手写题归档分支。包含此前所有前端手写题内容，不再新增题目，仅做纠错与维护。 |
| `main` | 主分支，承载转型后的新内容。 |

如需查阅此前的前端手写题，请切换至 `old-main` 分支。

## 目录结构

本仓库按**内容性质**而非技术方向组织，便于各自维护与贡献：

| 目录 | 定位 | 示例 |
| --- | --- | --- |
| [`problems/`](./problems) | 题目：手写题、算法题、场景题（带题解/讲解） | `debounce.md`、`two-sum.md` |
| [`notes/`](./notes) | 知识：原理笔记、源码解读、体系化总结 | 事件循环原理、某框架源码解读 |
| [`templates/`](./templates) | 资源：简历模板、自我介绍话术等可复用产物 | `resume/frontend-3y/` |
| [`career/`](./career) | 经验：面试复盘、职业规划、薪资/职级参考 | `interview-reviews/2026-08-某厂前端.md` |

各目录下均有 `README.md` 说明该目录的具体定位与贡献规则。

## 后续规划

`main` 分支及后续新建分支将从以下维度持续更新：

- **广度**：覆盖从业所需的基础知识，不局限于特定技术栈，涉及编程语言、数据结构与算法、工程化实践等多个领域。
- **深度**：在基础之上深入原理与底层实现，追求知其然更知其所以然。
- **AI 方向**：侧重 AI 相关技术，包括但不限于 AI 应用开发、Prompt 工程、AI 辅助编程实践等。
- **从业**：面向实际求职与职业发展，提供简历模板、面试复盘、职业规划等经验型与资源型内容（见 `templates/`、`career/`）。
